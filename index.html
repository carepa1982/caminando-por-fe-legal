Política de Privacidad

"Caminando por fe" es un proyecto de contenido audiovisual inspirador y de temática bíblica, publicado de forma automatizada en redes sociales (incluyendo TikTok) a través de una única cuenta propiedad del responsable de este proyecto.

¿Qué datos se recopilan?
Esta aplicación no recopila, almacena ni comparte datos personales de terceros. El único dato gestionado es el token de acceso y token de actualización (access token / refresh token) emitido por TikTok para autorizar la publicación de contenido en la propia cuenta de TikTok del responsable del proyecto ("Caminando por fe"), a través de la Content Posting API.

¿Cómo se usan estos datos?
Los tokens de acceso se usan exclusivamente para publicar videos generados por el propio responsable del proyecto en su cuenta de TikTok. No se recopila información de otros usuarios de TikTok, ni se accede a datos de audiencia, ni se comparte información con terceros.

Almacenamiento y seguridad
Los tokens se almacenan de forma privada en un servidor controlado por el responsable del proyecto, sin acceso público, y se utilizan únicamente dentro del flujo automatizado de publicación de contenido.

Servicios de terceros
Esta aplicación interactúa únicamente con la API oficial de TikTok (Content Posting API) para el propósito descrito anteriormente.

Términos de Servicio

Al utilizar la integración de "Caminando por fe" con la API de TikTok, se aceptan los siguientes términos:

  • Esta aplicación es una herramienta de uso interno, desarrollada y operada por el responsable del proyecto "Caminando por fe" para automatizar la publicación de su propio contenido original en su propia cuenta de TikTok.
  • No está diseñada para ser utilizada por terceros ni para gestionar cuentas de otros usuarios.
  • Todo el contenido publicado a través de esta integración es generado y/o supervisado por el responsable del proyecto, quien es el único titular de los derechos sobre dicho contenido.
  • El uso de esta integración está sujeto en todo momento a los Términos de Servicio y Políticas de la Plataforma para Desarrolladores de TikTok.
  • El responsable del proyecto se reserva el derecho de modificar o discontinuar esta integración en cualquier momento.

Política de Privacidad y Términos de Servicio — Integración con YouTube (Google API Services)

¿Qué datos se recopilan?
Esta aplicación no recopila, almacena ni comparte datos personales de terceros. El único dato gestionado es el token de acceso y de actualización (access token / refresh token) emitido por Google para autorizar la subida y gestión de contenido en el propio canal de YouTube del responsable del proyecto ("Caminando por fe"), a través de la YouTube Data API v3.

¿Cómo se usan estos datos?
Los tokens se usan exclusivamente para subir videos generados por el propio responsable del proyecto a su propio canal de YouTube, y para actualizar metadatos del video (título, descripción, estado de privacidad, y la marca de contenido alterado o sintético cuando corresponda). No se accede a datos de otros usuarios ni de la audiencia del canal, y no se comparte información con terceros.

Almacenamiento y seguridad
Los tokens se almacenan de forma privada en un servidor controlado por el responsable del proyecto, sin acceso público, y se utilizan únicamente dentro del flujo automatizado de publicación de contenido.

Cumplimiento
Esta aplicación cumple con los Términos de Servicio de la API de Servicios de YouTube (YouTube API Services Terms of Service) y con la Política de Privacidad de Google.
